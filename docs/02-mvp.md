# MVP 범위 & 기술 스택

> 상태: 초안 (2026-11-08)
> 기준 문서: [01-prd.md](01-prd.md)
> 표기: **확정** = 논의해서 정함 / **제안** = 기본값으로 채운 것, 바꿔도 됨

## 1. 전제

| 항목 | 내용 | 상태 |
|---|---|---|
| 개발 인원·기간 | 1인, 첫 MVP 약 3개월 | 확정 |
| 타깃 지역 | 해외여행 전용 (국내 길찾기 미지원) | 확정 |
| 플랫폼 | iOS · Android 모바일 앱 | 확정 |

해외 전용으로 정한 이유: Google 지도는 한국 안에서 자동차·도보 길찾기를 제공하지 않는다. 국내까지 하려면 카카오·네이버 지도 API를 따로 붙여야 해서 1인 3개월 범위를 넘는다.

## 2. MVP 범위

### 포함

**[M1] 스마트 일정 & 동선 자동화**
- 여행(Trip) 만들기: 이름, 목적지, 기간
- 일자별 일정에 장소 추가·삭제·순서 변경 (Google Places 검색)
- 장소와 장소 사이 이동시간·이동수단 자동 계산 (Google Routes API: 차량/대중교통/도보)
- 지도에서 하루 동선 보기
- 제외: 동선이 꼬였을 때 경고·순서 재배치 제안 → 2차

**[M4] 동행자 협업 & 오프라인 바우처 지갑**
- 초대 링크로 동행자 초대, 권한은 편집자 / 보기 전용 두 가지
- 링크 만료·폐기, 멤버 내보내기
- 공유는 OS 공유 시트로 처리 (카카오톡도 여기서 선택 가능)
- 공동 편집은 **새로고침 동기화**: 앱을 열거나 당겨서 새로고침할 때 반영. 동시에 고치면 버전 번호로 충돌을 감지하고 사용자에게 알림
- 바우처(PDF·이미지) 업로드, 날짜·일정 항목에 연결
- 오프라인 열람: 바우처와 일정은 데이터 없이 **읽기 가능**
- 제외: AI 준비물 체크리스트(LLM 필요) → 2차, 오프라인 상태에서 수정 후 나중에 병합 → 2차

**공통**
- 소셜 로그인: 카카오 · Apple · Google (이메일/비밀번호 없음)
- 회원 탈퇴 (앱스토어 심사 필수 항목, 개인정보 삭제 포함)

### 2차 이후로 미룸

| 항목 | 미루는 이유 |
|---|---|
| M2 AI 코파일럿, M3 도슨트 | LLM 비용, 프롬프트 인젝션 대응 설계 필요. 보안 로드맵 6단계(LLM 보안)와 같이 진행 |
| M5 가계부·정산 | MVP 범위 초과. 금액 계산·동시성 이슈는 2차에서 집중적으로 다룸 |
| 실시간 공동 편집 (WebSocket) | 연결 관리, 권한 재확인, 충돌 병합까지 1인 3개월로는 부담 |
| 카카오톡 공유 SDK (예쁜 카드 메시지) | OS 공유 시트로 대체 가능 |
| 국내 여행 | 위 1번 참고 |

## 4. 주요 설계 결정

**Google API는 백엔드를 거쳐 호출한다 (제안)**
앱에 API 키를 넣으면 추출당할 수 있고, 남이 내 키로 호출하면 요금이 나온다. 백엔드가 키를 들고 사용자별 호출 횟수를 제한한다. 지도 표시용 키만 앱에 넣고, 앱 번들 ID로 사용 범위를 묶는다.

**인증 흐름 (제안)**
앱이 소셜 로그인으로 ID 토큰을 받는다 → 서버가 서명·발급자·대상(aud)·만료를 검증한다 → 서버가 자체 토큰을 발급한다. 액세스 토큰은 짧게(15분 안팎) 두고, 리프레시 토큰은 쓸 때마다 새로 바꾸고(rotation) DB에서 폐기할 수 있게 한다.

**초대 링크 (제안)**
추측할 수 없는 랜덤 토큰을 쓰고, DB에는 해시만 저장한다. 링크마다 권한·만료 시각·사용 횟수 제한을 두고 폐기할 수 있다. 링크를 열면 로그인한 뒤에 멤버로 추가된다.

**공동 편집 충돌 처리 (제안)**
일정 데이터에 `version` 컬럼을 둔다. 수정 요청에 버전을 같이 보내고, 서버 버전과 다르면 409로 거절한다. 앱은 최신 데이터를 다시 받아 사용자에게 보여준다.

**바우처 저장 (확정: 서버 + 기기 캐시)**
- 서버: 오브젝트 스토리지에 암호화해서 저장. 다운로드는 권한을 확인한 뒤 짧게 만료되는 URL로만 허용
- 기기: 암호화해서 캐시, 로그아웃·탈퇴하면 삭제
- 업로드 검증: 파일 크기 제한, 확장자가 아니라 실제 파일 형식으로 판별 (PDF·JPEG·PNG만 허용)
- 공개 범위 (제안): 기본은 **올린 사람만** 보고, 원하면 여행 멤버와 공유. 여권번호 같은 개인정보가 들어 있어서
